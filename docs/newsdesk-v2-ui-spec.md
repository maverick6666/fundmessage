## 1. 전체 구조

기존 뉴스데스크(v1) 페이지를 **완전 교체**한다. v1의 브리핑 기능은 v2에 포함된다.

```
라우트: /newsdesk (기존과 동일)

┌─────────────────────────────────────────────────────────┐
│ [코스피 카드] [코스닥 카드] [나스닥 카드] [비트코인 카드]  │  ← 상단 지수 카드 4개
├─────────────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────────────┐ │
│ │          증시 브리핑 패널 (접힘/펼침)                 │ │  ← 카드 클릭 시 펼쳐짐
│ └─────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────┤
│                                                         │
│              섹터 히트맵 (핀비즈 스타일)                  │  ← 선택된 장에 맞춰 전환
│                                                         │
└─────────────────────────────────────────────────────────┘
                        │
                  종목 클릭 시
                        ▼
              ┌─────────────────┐
              │  사이드 패널     │  ← 우측에서 슬라이드
              │  - 차트          │
              │  - 회사 정보     │
              │  - 당일 요약     │
              │  - 뉴스 타래     │
              └─────────────────┘
```

---

## 2. 상단 지수 카드 (4개, 가로 배치)

### 구성
| 카드 | 장 마감 기준 |
|------|-------------|
| 코스피 | 국장 마감 (KST ~15:30) |
| 코스닥 | 국장 마감 (KST ~15:30) |
| 나스닥 | 미장 마감 (KST ~06:00) |
| 비트코인 | 미장 마감과 동시 처리 |

### 카드 내부 표시
- 지수명 (코스피, 코스닥, NASDAQ, BTC)
- 현재 지수값 / 가격
- 전일 대비 등락 (금액 + 퍼센트)
- 등락 색상: 상승=빨강, 하락=파랑 (한국식)

### 동작
- **카드 클릭** → 해당 장의 증시 브리핑 패널이 카드 하단에 펼쳐짐
- **카드 선택** → 아래 히트맵이 해당 장으로 전환
  - 코스피 선택 → 코스피 섹터 히트맵
  - 코스닥 선택 → 코스닥 섹터 히트맵
  - 나스닥 선택 → 나스닥 섹터 히트맵
  - 비트코인 선택 → 크립토 히트맵
- 선택된 카드는 시각적으로 활성 상태 표시 (테두리, 배경 등)

---

## 3. 증시 브리핑 패널

카드 하단에 직사각형 패널로 펼쳐진다. 다른 카드를 클릭하면 해당 장 브리핑으로 전환. 같은 카드를 다시 클릭하면 접힘.

### 내용
- AI 생성 장 요약 코멘트 (market_summary.ai_summary)
- 거래량, 거래대금
- 상승/하락/보합 종목 수
- 업종별 등락 요약

---

## 4. 섹터 히트맵 (핀비즈 스타일)

### 레이아웃
- **Finviz S&P 500 Map**과 동일한 트리맵 형태
- 섹터(업종)별로 종목들이 시각적으로 그룹핑
- 블록 크기: 시가총액 비중에 비례
- 블록 색상: 등락률 기반 그라데이션
  - 진한 빨강: 강한 상승 (+3% 이상)
  - 연한 빨강: 약한 상승
  - 회색/흰색: 보합
  - 연한 파랑: 약한 하락
  - 진한 파랑: 강한 하락 (-3% 이상)
- 블록 내 텍스트: 종목명 + 등락률

### 동작
- **종목 블록 클릭** → 우측 사이드 패널에 종목 상세 열림
- 선택된 상단 카드(장)에 따라 히트맵 데이터 전환
- hover 시 종목 정보 툴팁

---

## 5. 종목 상세 사이드 패널

히트맵에서 종목 클릭 시 우측에서 슬라이드로 열린다. 기존 SidePanel 컴포넌트 활용.

### 섹션 (위에서 아래로)

#### 5.1 차트
- 기존 lightweight-charts 캔들차트 재활용
- 기간 선택 가능 (1W, 1M, 3M 등)

#### 5.2 회사 정보
- 종목코드, 종목명
- 시장 (KOSPI, NASDAQ 등)
- 업종
- 시가총액
- PER, PBR 등 (데이터 있을 경우)

#### 5.3 당일 움직임 요약
- 시가, 고가, 저가, 종가
- 거래량
- 등락률
- 전일 대비 변동

#### 5.4 뉴스 타래 (핵심 섹션)

**관련도 점수(relevance_score) 내림차순으로 정렬된 뉴스 스레드.**

핵심 설계 원칙:
- **날짜별이 아닌 관련도 기반 누적형**
- 가장 관련도 높은 뉴스가 상단, 낮은 뉴스가 하단
- 업로드가 불규칙해도 빈 페이지가 생기지 않음
- 새 업로드 시 기존 타래 사이에 관련도 점수 기준으로 자연스럽게 삽입

각 뉴스 아이템 표시:
- 관련도 점수 배지 (예: `[95%]`, `[72%]`)
- 뉴스 제목
- 매체명 + 발행일시
- 요약 미리보기 (1-2줄)
- 클릭 시 원문 링크 새 탭
- **NEW 태그**: 최근 업로드된 뉴스에 표시

필터:
- **종합** (기본): 날짜 무관, 관련도순 전체
- **최신**: 최근 업로드분만 필터 (coupled_at 기준)
- 단순 필터링으로 구현 (관련도 정렬은 동일하게 유지)

## 6. 데이터 갱신 주기

하루 2회, 장 마감 기준 자동 실행 (뉴스데스크 센터, 로컬 PC).

| 시점 | 트리거 | 작업 |
|------|--------|------|
| **국장 마감** (KST ~15:30) | 자동 | 코스피/코스닥 시세 수집 + 뉴스 수집/커플링 + 국장 증시요약 + 국장 종목 당일요약 |
| **미장 마감** (KST ~06:00) | 자동 | 나스닥/비트코인 시세 수집 + 뉴스 수집/커플링 + 미장 증시요약 + 미장 종목 당일요약 |

- PC를 장 마감 전에 켜고 프로그램 실행하면 자동으로 처리
- 뉴스 타래는 각 시점마다 새 뉴스 추가 (교체가 아닌 누적)

## 7. 디자인 참조

- **핀비즈(Finviz)**: 히트맵 레이아웃, 색상 체계, 종목 그룹핑

## 8. 기존 v1 대비 변경점

| v1 | v2 |
|----|-----|
| 날짜별 브리핑 (달력 선택) | 장 마감 기준 자동 브리핑 |
| AI 칼럼 + 뉴스카드 | 지수 카드 + 증시 브리핑 패널 |
| 키워드 버블 + 탐욕/공포 지수 | 섹터 히트맵 (핀비즈) |
| 주목종목 TOP3 | 종목 클릭 → 사이드 패널 (차트+정보+뉴스 타래) |
| 수동 날짜 탐색 | 관련도 기반 누적형 뉴스 |
| GPT 단일 호출 | 뉴스데스크 센터 자동 파이프라인 |
